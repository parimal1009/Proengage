## 🌟 Features

- **AI-Powered Chat Interface** with document understanding
- **Lead Management System** with tracking and analytics
- **Email Campaign Management** with templates and tracking
- **Document Intelligence** for PDF processing and Q&A
- **Video Tutorials** management system
- **Analytics Dashboard** with visual insights
- **Role-Based Access Control** (Admin/User)
